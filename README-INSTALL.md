# Chest-Priority Smart Training — Smart Coach 3.0

Deploy all files from this ZIP to the *same* GitHub Pages repository that hosts your current app. **Back up your existing data in Settings first.** Do not clear browser storage, replace your Firebase config or create a new Firebase account.

After uploading, reload the website; for a home-screen app, close and reopen it. You may need to clear the cached version if your device still shows the old build. Your cloud-synced workout history is associated with the existing Firebase account.

Read `PHASE-1-RELEASE-NOTES.md` before starting a new block. Existing weeks stay intact during deployment. **Starting a new block is a separate, explicit Settings action.**
